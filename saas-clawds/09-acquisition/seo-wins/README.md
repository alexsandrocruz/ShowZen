## Technical SEO Audit Checklist (ABP.io / React)
- [ ] Page speed score > 90 (Use Vite optimizations).
- [ ] Mobile responsiveness (Crucial for producers on the road).
- [ ] XML sitemap submitted (Google Search Console).
- [ ] Robots.txt configured.
- [ ] Schema markup for Product and SoftwareApplication.
- [ ] Canonical URLs set on the React frontend.
- [ ] Core Web Vitals passing.
- [ ] Image optimization (WebP for artist logos/hero).

## Link Building Plan
- **Target:** 5 quality backlinks per month.
- **Tactics:**
    - Guest posts on music industry blogs (e.g., Tenho Mais Discos Que Amigos, PopLine).
    - Partnerships with Regional Artist Associations.
    - SEO Link Magnets: "Planilha gratuita de orçamento de show" (leads to a trial).
    - Original Research: "O estado do mercado de shows no Brasil em 2026".

## Competitor SEO Analysis
- **Direct Competitors:** Logic (Event management), generic CRMs (Pipedrive).
- **Competitor Gaps:** Most lacks deep BRL tax integration and "Agenda-first" UX.
- **Keywords to Win:** Specific Brazilian terms like "venda de shows", "mapa de produção", "rider técnico".
