# Product Roadmap: ShowZen

## Vision Statement
> To be the definitive business operating system for artistic producers in Brazil, automating the entire workflow from initial talent scouting to final event settlement.

## Now / Next / Later

### 🔨 NOW — Q1 2026 (MVP Development)
*Focused on delivering the core value to Divina Providência.*

| Feature/Initiative | Description | Owner | Target Date | Status |
|---|---|---|---|---|
| Multi-artist Agenda | Centralized visual calendar with color-coded artist events. | Dev | Feb 2026 | In Progress |
| Conflict Detection | Automatic alerts for overlapping artist dates/times. | Dev | Feb 2026 | Not Started |
| CRM Core | Artist/Client/Partner registration and basic pipeline. | Dev | Feb 2026 | Not Started |
| Automatic Proposals | One-click PDF generation with branding and finance data. | Dev | March 2026 | Not Started |
| Financial Automation | BRL Tax and internal commission calculations. | Dev | March 2026 | Not Started |

### 📋 NEXT — Q2 2026 (Growth & Polish)
*Expanding features for secondary personas and management efficiency.*

| Feature/Initiative | Description | Why Now | Dependencies |
|---|---|---|---|
| Dashboard Analytics | KPIs on revenue, events by status, and regional maps. | Business visibility | Financial Data |
| Mobile-Optimized View| Simplified view for Roadies and Artists on tour. | Field accessibility | Core Agenda |
| Public Proposal Link | Tracking when clients view the online proposal. | Increase conversion | PDF Engine |
| CRM Quick-Add | Modal-based addition of clients during event creation. | UX efficiency | CRM Core |

### 🔮 LATER — Q3 2026+ (Scaling)
*Advanced integrations and ecosystem growth.*

| Feature/Initiative | Description | Why It Matters |
|---|---|---|
| Logistics Module | Hotel/Travel/Rider automation integrated with events. | Completes the workflow. |
| Split Payment | Automated payment distribution between agency and artist. | Monetization layer. |
| API / Integrations | Sync with Google Calendar, Instagram, and ERPs. | Ecosystem play. |

### 🚫 NOT DOING (Explicitly Deferred)
| Feature | Why We're Not Building It | Revisit When |
|---|---|---|
| Native iOS/Android App | Web responsive is enough for the current niche scale. | Scale > 50 agencies |
| International Currency | Focus is 100% on the Brazilian market (BRL). | Int. expansion |
