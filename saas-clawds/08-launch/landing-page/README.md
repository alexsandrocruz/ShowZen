# Landing Page: ShowZen

## Overview
ShowZen is live at [eventos.zensuite.com.br](https://eventos.zensuite.com.br). The landing page is designed to convert artistic managers and producers by highlighting the core "Agenda-First" value proposition.

## Target Audience
- **Primary:** Artistic Managers and Representation Offices in Brazil.
- **Tone:** Professional, modern, and results-oriented.

## Core Sections & Messaging

### 1. Hero Section
- **Headline:** Gestão de Agenda e Eventos para Produtoras Artísticas.
- **Sub-headline:** Elimine conflitos de agenda, automatize orçamentos e tenha controle financeiro total dos seus artistas em uma única plataforma.
- **CTA:** [Botão de Cadastro/Login]

### 2. Pain Points & Solution
- **The Problem:** Agendas fragmentadas, orçamentos manuais e falta de visibilidade financeira.
- **The Solution:** Visualização unificada, detecção automática de conflitos e geração de propostas em PDF.

### 3. Key Features
- **Agenda Inteligente:** Calendário multi-artista com cores personalizadas.
- **Alertas de Conflito:** Notificações em tempo real para evitar erros de reserva.
- **Propostas Automáticas:** Gerador de orçamentos profissionais com um clique.
- **Financeiro BRL:** Cálculos automáticos de impostos e comissões no padrão brasileiro.

### 4. Direct Client Case (Divina Providência)
- **Messaging:** Built for real-world production offices management.
- **Social Proof:** Practical application in managing career artists.

## SEO Metadata
- **Title:** ShowZen | Gestão de Agenda para Produtoras Artísticas
- **Description:** Sistema SaaS para gestão de shows, agenda de artistas e automação de orçamentos para produtores artísticos e agências.
- **Keywords:** gestão de artistas, agenda de shows, produtora artística, software para eventos, orçamento de show pdf.

## Conversion Strategy
- **Primary Goal:** Lead conversion for the "Event Module".
- **Tracking:** User entry via public URL and navigation to the functional dashboard.
