# Beta Users: Divina Providência Case

## Beta Partner
- **Name:** Divina Providência (Artistic Production Office).
- **Stage:** Founding Customer / Active Beta User.
- **Investment:** R$ 10.000,00 for initial development.

## Onboarding Process
1. **Initial Requirement Mapping:** Based on the [Módulo de Eventos PRD](../../docs/PRD-modulo-eventos-dominus.md).
2. **Setup:** Provisioning the instance at `eventos.zensuite.com.br`.
3. **Training:** Face-to-face or virtual walk-through of the Agenda and Financial features.
4. **Data Migration:** Importing the current artist roster and event history.

## Feedback Loop
- **Method:** Continuous sync via WhatsApp and direct system usage observations.
- **Key Insights Provided:**
    - Essential need for automatic conflict detection (Agenda).
    - Importance of branding on PDF proposals (Commercial).
    - Requirement for Brazilian tax calculations for public sector contracts (Financial).

## Graduation Criteria (Moving to Public Release)
- [x] Successful booking of 20+ live events with no conflicts.
- [x] Successful generation of 10+ PDF proposals used in sales.
- [x] Financial reports matching the agency's accounting expectations.
- [x] System stability with 99.9% uptime for the office.

## Case Study Outline
- **Before ShowZen:** Manual sheets, fragments of info on WhatsApp, constant risk of double-booking.
- **After ShowZen:** One "source of truth", professional automated proposals, financial peace of mind.
